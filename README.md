# free-mac-cleaner
its a mac cleaning tools for free, enjoy!
download the free-mac-cleaner zip file
In Terminal, type this and press Enter:
   cd /Users/admin/Downloads/FreeMacCleaner-Native

Remember the space after cd.

Check that you are in the right place by typing:
   ls

You should see build.sh, main.swift, FreeMacCleaner.py, Info.plist, AppIcon.icns and README.txt.

Build the app:
   ./build.sh



   If it says permission denied, run chmod +x build.sh and then ./build.sh again.
If macOS asks to install Command Line Tools, click Install and wait. When it finishes, run ./build.sh again.
When you see “Done!”, drag FreeMacCleaner.app into your Applications folder and open it.
